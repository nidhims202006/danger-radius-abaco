Phase 2 is the implementation stage following the frozen Phase-1 evaluation design.

## Required before confirmation execution

1. `docs/EVAL_PROTOCOL_v2.md` remains unchanged and its SHA-256 remains recorded.
2. Both named co-authors explicitly confirm that they have read and approved the protocol.
3. Any protocol amendment is recorded and re-hashed before confirmation execution.
4. Confirmation results are not inspected before code/parameter hashes and the analysis plan are frozen.

- 2.4 D* Lite + DWA/MPC-style local planner on the same grid/world interface.
- 2.5 Scenario generator: >=200 independent scenarios covering the protocol's workspace, density, dynamic-obstacle, motion and noise factors.
