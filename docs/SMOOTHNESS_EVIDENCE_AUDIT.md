# Smoothness evidence audit

Date: 2026-10-02

## Review closure

The manuscript previously risked implying that the closed-loop confirmation established a smoothness/path-quality advantage. That implication is not supported by the primary closed-loop evidence.

### Evidence boundary

- Table 7 is a **post hoc five-seed closed-loop variance study** on the same 200-scenario set. Its sharp-turn values are descriptive seed-variance characterization only.
- The primary closed-loop confirmation does not use sharp turns as a primary inferential endpoint. Therefore Table 7 is not used to establish a closed-loop smoothness advantage.
- Smoothness/path-quality comparisons are retained only for the **fixed-grid development and confirmation blocks**, where sharp turns and path length were explicitly measured under the iteration-indexed protocol.

### Manuscript changes

- Section 5.3 now contains an explicit smoothness-evidence boundary statement after the Table 7 interpretation.
- The fixed-grid development discussion identifies its sharp-turn/path-length results as fixed-grid descriptive evidence and no longer cites Table 7 as support.
- The fixed-grid confirmation discussion is explicitly labelled as such and states that those results are not generalized to closed-loop smoothness.

This audit does not change any stored numerical results.
