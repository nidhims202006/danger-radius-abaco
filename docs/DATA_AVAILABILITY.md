# Data availability

All manuscript-derived result files and analysis scripts used for the reported simulation studies are included in this reproducibility archive. The primary closed-loop scenarios, fixed-grid result files, statistical analysis outputs, and manifest files are retained under `results/`, `experiments/`, and `docs/`.

A 24-scenario warehouse-style generator is included as `experiments/warehouse_scenario_generator.py`; it is a validation protocol artifact and is not presented as completed experimental evidence in v29.

A public repository and DOI are not yet minted.
