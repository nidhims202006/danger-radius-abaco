# Data Availability Statement

The code, configuration files, scenario seeds, raw per-run results, generated result summaries, analysis scripts and supporting reproducibility materials are publicly available through the project GitHub repository (https://github.com/nidhims202006/danger-radius-abaco.git) and the Zenodo reproducibility archive at DOI 10.5281/zenodo.23106834.

The archive includes the R = 5.5 re-evaluation, the R = 4.5 reference rerun, high-fidelity continuous-kinematic validation and paired statistical analyses.

The Zenodo DOI provides the persistent archival and citable identifier for the released materials.
